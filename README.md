# deno_audio

A [Web Audio API](https://webaudio.github.io/web-audio-api/) extension for
[`deno_core`](https://crates.io/crates/deno_core), in the style of Deno's
standard Web Platform extensions, delegating DSP and rendering to
[`web-audio-api-rs`](https://crates.io/crates/web-audio-api).

**Status: under active development.** This release intentionally contains no
functionality; it reserves the crate name while the implementation is built.
Do not depend on this version.
